# FekaMovies

Este proyecto es independiente de betanalytics y Xuper TV. Trabaja únicamente dentro de esta carpeta.

La aplicación está en outputs/ y usa HTML/CSS/JavaScript, un servidor Node.js y Netlify Functions. No es una aplicación Next.js.

Antes de modificar la aplicación, consulta README.md, outputs/README.md y la documentación del área afectada. No incluyas claves privadas en archivos públicos ni publiques outputs/ completo; el build publica outputs/dist.

Verificación de fútbol: node --test outputs/tests/football.test.cjs
Verificación del reproductor: node outputs/tests/football-player.cjs
